# AMG Intelligent Document Platform

## Project Description

AMG Intelligent Document Platform is an enterprise-grade intelligent document processing platform built on top of AMG Integration Platform (AIP). AIP is a mature file integration platform that handles multi-channel connectivity (Email, SFTP, REST API, Web Portal), workflow orchestration, file routing, and audit logging across enterprise systems. AMG Intelligent Document Platform extends AIP with an AI Intelligence Layer — a multi-agent AI engine powered by RAG (Retrieval-Augmented Generation) and LLM — transforming AIP from a file integration platform into a file intelligence platform.

The first AI-powered product is **Questionnaire Auto-Response**: clients send questionnaire documents through any AIP channel, the AI engine automatically extracts questions, searches a centralized knowledge base for relevant information, generates traceable answers with confidence scores and source references, routes answers through a configurable approval workflow (auto-approve, single review, or escalation based on confidence), and delivers the completed document back to the client. All reviewer feedback — accepts, edits, and rejections — feeds into a continuous improvement loop that automatically detects knowledge gaps and updates the knowledge base, making the system smarter with every interaction.

The platform is designed to scale beyond questionnaires into contract review, RFP automation, and compliance checks — any document workflow where enterprise files need intelligent understanding and response.

## E2E Workflow

1. **Document Arrival** — Client sends a questionnaire (Word/Excel) via Email, SFTP, API, or Web Portal. AIP receives the file through Channel Adapters.

2. **Ingestion & Routing** — AIP validates the file, extracts metadata, classifies it as a questionnaire, and routes it to the AI Engine via async API (`POST /api/engine/process`).

3. **AI Processing** — The AI Engine's multi-agent system processes the document: Document Analyzer extracts all questions, Answer Generator searches the Knowledge Base (RAG) and calls LLM to generate answers with confidence scores and source references, Document Writer fills the answers back into the original document.

4. **Approval Routing** — AI Engine calls back AIP with results. The Approval Policy Engine routes each answer based on confidence: ≥85% auto-approved, 60–85% assigned to a single reviewer, <60% or sensitive topics escalated to dual review.

5. **Human Review & Feedback** — Reviewers accept, edit, or reject each flagged answer. All decisions are logged in the Feedback Store. Rejected answers are re-generated by the AI Engine with additional context.

6. **Finalize & Deliver** — AIP merges all approved answers into the final document, attaches an audit trail with source traceability, and delivers back to the client via the original channel.

7. **KB Auto-Update** — The Knowledge Base continuously improves: repeated corrections flag knowledge gaps, quality edits become new KB entries, and new reference documents from AIP channels or scheduled scans are automatically chunked, embedded, and indexed.
