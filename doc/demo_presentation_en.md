# AI Audit Assistant — Demo Presentation Script (English)

## AI questionnaires Project Overview

- **Goal:** Help the team automatically process questionnaires and quickly produce professional, traceable answers, saving time on manual organization and search.
- **User Flow (one line):** Upload questionnaire → AI Capabilities(system identifies questions → retrieve relevant knowledge → generate answers → write answers back to document for download).
- **Key Roles (non-technical):**
  - **Orchestrator:** Assigns tasks and combines results.
  - **Document Analyzer:** Reads uploaded documents and finds the questions.
  - **Answer Generator:** Searches the internal knowledge base and produces audit-appropriate answers while recording sources.
  - **Document Writer:** Writes answers back into Word/Excel while preserving format.
- **Search & Traceability:** A searchable knowledge base is used to find the most relevant passages; every generated answer includes references to its source for auditability.
- **Other Capabilities:** Supports multiple formats (.docx/.xlsx/.md/.txt), offers OAuth or API key auth, supports corporate proxies, and persists tokens in user cookies for reuse.
- **Business Value:** Faster questionnaire processing, more consistent answers, traceable evidence for compliance, and reduced repetitive work.

## Demo Presentation Script (Non-Technical)

### Opening (≈15s)

- Hello — I’m presenting the AI Audit Assistant, which automatically turns audit questionnaires into structured, traceable answers, reducing manual lookup and editing time.

### One-line Value Proposition (≈10s)

- This tool automates questionnaire processing and saves the supporting sources with each answer, improving efficiency and compliance.

### Core Selling Points (≈30s)

- Automatically detects questions and provides answers (no manual line-by-line searching).
- Preserves Word/Excel format so output is ready to send.
- Each answer includes source tracking for easy verification.

### Live Demo Flow (2–3 minutes)

1. Show homepage briefly (10s)
   - Script: “This is the homepage where you can upload files or manage the knowledge base.”
2. Show the knowledge base (20s)
   - Script: “Our policies and guidelines live here; the system searches these documents for evidence.”
3. Upload a sample document and start processing (40–60s)
   - Script: “I’ll upload a questionnaire. The system will automatically detect questions, search the knowledge base, and generate answers.”
4. Review results and sources (30–40s)
   - Script: “Each answer lists the document excerpts used as evidence, so reviewers can trace the rationale.”
5. Download the filled document (20s)
   - Script: “Here’s the final file — answers are filled in and the format is preserved, ready for distribution.”

### Risk & Compliance Note (≈20s)

- Script: “Authentication supports OAuth or enterprise tokens, proxy settings are available, and every answer is source-traced for compliance.”

### Closing & Next Steps (≈15s)

- Script: “If you approve, we can run a pilot on one or two real questionnaires to measure time saved and answer quality, then consider wider rollout.”

### Q&A Prep (optional)

- Be ready to answer: “How is source accuracy ensured?”, “Which file formats are supported?”, “How is data stored and access controlled?”
